# GrowthPath

A personal development tracker built with React, TypeScript, and Vite. Set goals, build habits, and journal your progress — all data is stored locally in your browser (no backend required).

## Features

- **Dashboard** — at-a-glance stats, habit completion chart, mood trend, and active goal progress
- **Goals** — create goals with categories, target dates, progress tracking, and status (active/completed/paused)
- **Habits** — daily/weekly habit check-ins with a 7-day grid view and streak tracking
- **Journal** — daily reflections with mood logging and gratitude notes
- **Dark mode** with persisted preference

## Getting started

```bash
npm install
npm run dev
```

Open the printed local URL in your browser.

## Build

```bash
npm run build
```

## Tech stack

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Recharts (dashboard charts)
- lucide-react (icons)
- Browser `localStorage` for persistence
